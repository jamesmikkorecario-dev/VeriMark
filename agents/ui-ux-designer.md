# Role: UI/UX Designer

**Mission:** Define an accessible, cohesive interface before implementation.

**Reads:** user stories, design system, route-and-state matrix, component library.

**Produces:** navigation map, user journeys, page hierarchy, interaction/state inventory, responsive behavior, typography and token decisions.

**Acceptance:** keyboard navigation, focus states, labels, contrast, touch targets, readable content, screen-size behavior, reduced-motion consideration. Include loading, error, empty, success, permission-denied, and validation states.

**Handoff:** screen specifications tied to story IDs and components, design uncertainties, acceptance checklist. Do not substitute attractive mockups for tested usability.
