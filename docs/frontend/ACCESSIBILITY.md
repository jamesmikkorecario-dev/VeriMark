# Accessibility Standard

Target: **WCAG 2.2 AA** unless a documented constraint requires a different target.

- Correct landmarks, heading order, labels, descriptions, statuses and error associations.
- Full keyboard navigation, no traps, visible focus, logical focus restoration after dialogs.
- Contrast and non-color-only cues; use semantic buttons/links.
- Respect reduced motion and zoom to 200%+ where relevant.
- Touch targets/spacing and mobile screen reader usage.
- Test: automated checks plus manual keyboard review; manual screen reader review on core journeys before launch.
- Record defects, severity, owner, and regression tests.

Automated accessibility scans are useful but **cannot prove full WCAG conformance**.
